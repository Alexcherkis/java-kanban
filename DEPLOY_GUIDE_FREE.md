# Как разместить сайт БЕСПЛАТНО и НАВСЕГДА

Поскольку у вас закончилась оплата хостинга, но сам сайт у вас "на руках" (файлы на компьютере), мы можем разместить его на современных "облачных" платформах. Это бесплатно, быстрее обычных хостингов и идеально подходит для React/HTML сайтов.

## ВАЖНО: Домен vs Хостинг
- **Хостинг** (где лежат файлы) — мы сделаем **бесплатным**.
- **Домен** (имя `direct-sites.ru`) — за него **нужно платить** регистратору (обычно раз в год ~200-900 руб). Если вы не оплатили продление самого имени, то его могут забрать. Если закончился только хостинг — всё отлично.

---

## Вариант 1 (Рекомендую): Vercel
Это "Apple" в мире хостингов. Самый быстрый, надежный и стильный вариант.

### Инструкция:
1. Зарегистрируйтесь на [vercel.com](https://vercel.com) (можно войти через GitHub или почту).
2. Установите их утилиту (в терминале вашего компьютера):
   ```bash
   npm i -g vercel
   ```
3. Находясь в папке с сайтом, введите команду:
   ```bash
   vercel login
   # (следуйте инструкциям для входа)
   vercel
   # (на все вопросы жмите Enter)
   ```
4. **Готово!** Вы получите ссылку вида `project-name.vercel.app`.
5. **Привязка домена `direct-sites.ru`**:
   - В панели Vercel зайдите в **Settings -> Domains**.
   - Введите `direct-sites.ru`.
   - Vercel покажет **DNS записи** (обычно это A-запись `76.76.21.21`).
   - Зайдите на сайт, где покупали домен (Reg.ru, Nic.ru и т.д.), и в настройках DNS пропишите эти значения.

---

## Вариант 2 (Самый простой): Netlify Drop
Если не хотите пользоваться терминалом.

1. Зайдите на [netlify.com](https://www.netlify.com/drop/).
2. Просто **перетащите папку** с вашим сайтом в окошко "Drag and drop your site folder here".
3. Сайт мгновенно опубликуется.
4. В настройках сайта (Domain Management) добавьте ваш домен `direct-sites.ru` по аналогии с Vercel.

---

## Вариант 3: GitHub Pages
Если у вас есть аккаунт на GitHub.

1. Создайте репозиторий `username.github.io` (или любое имя).
2. Загрузите туда файлы сайта.
3. В настройках репозитория (Settings -> Pages) включите GitHub Pages.

---

### Моя рекомендация
Выбирайте **Vercel** или **Netlify**. Для React/статических сайтов они работают намного быстрее и стабильнее российских платных хостингов, плюс у них есть бесплатный SSL (замочек) и защита от атак.

**Никаких ежемесячных платежей за сервер больше не будет!** 🚀
