# Проект: Gym Master (Спринт 6)

Привет! Это доработка программы для управления гимнастическим залом.
Приятель попросил помочь с расписанием, чтобы админам было легче.

### Что сделано:
1.  **Хранение расписания:** Решил использовать `Map` с днями недели и временем, чтобы поиск работал максимально быстро.
2.  **Поиск по дню:** Реализовал возврат списка всех тренировок на день. Они автоматически сортируются по времени при добавлении.
3.  **Поиск по времени:** Сделал вторую мапу-индекс, чтобы можно было за O(1) найти, что там идет в конкретный час.
4.  **Статистика:** Метод для подсчета нагрузок тренеров (кто больше всех работает — тот вверху списка).

### Структура:
- В `model` лежат основные сущности (тренеры, группы и само время).
- В `service` лежит класс `Timetable`, там вся логика.
- В `test` лежат JUnit тесты, чтобы проверить, что ничего не ломается.

### Как проверить сам запуск:
Я добавил класс `Main` в корне папки `ru.gymmaster`. Там просто пара примеров, как всё работает, и вывод в консоль.
Для запуска тестов используй стандартный запуск JUnit.
